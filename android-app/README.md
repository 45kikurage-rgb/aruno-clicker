# ARUNO CLICKER

## v0.4.1

- ホーム画面のアプリアイコンをAdaptive Iconへ統一し、端末側の丸・角丸・八角形の枠内いっぱいに表示します。
- 固定のリリース署名へ切り替え、v0.4.1以降はアンインストールせず上書き更新できるようにしました。
- v0.4.0以前は一時的なデバッグ署名だったため、v0.4.1への移行時だけ旧版のアンインストールが必要です。

Matrix風の外観を持つ、TikTok Lite向けのAndroid自動スライドアプリです。

## v0.4.0で使える機能

- TikTok Liteを起動し、アクセシビリティ機能で縦方向に自動スライド
- 通常画面は7・8・9秒からランダムで選び、広告等の判定中も通常タイマーを止めずに優先
- 7・8・9秒ランダムのON/OFFを基本動作の最上部に表示。ONの間は指定秒数スライダーを無効化
- トップ画面に通常スライド、高速スライド、連続判定回数を表示
- 高速対象は同じ種類を1〜3回連続で検出した場合だけ確定（初期値2回、1回＝誤判定が起きやすい／2回＝推奨／3回＝安定版）
- 通常スワイプは初期300ms、画面高56%から29%へ実行
- サークルゲージがない画面は高速設定で強制スライド
- 広告・写真・テキスト画像を可視中の画面要素から判定できた場合、初期値2秒・150msの高速設定へ切替
- 画面中央下の限定範囲に並ぶ写真ページのドットを画像判定し、高速設定で強制スライド
- 判定が確定しない場合は高速スライドへ切り替えず、通常の7・8・9秒でスライド
- スワイプ後に画面更新を待って次の投稿を判定し、広告用の短い待機が通常投稿へ引き継がれないよう制御
- 写真バッジ、`1/7`、`1／7`などの写真カルーセル表示を認識
- 開始時はTikTok Liteの既存タスクをクリアしてメイン画面を新規起動（アプリデータは消去しません）
- スライド動作中は、画面上端から90%以内に表示された `×`・`閉じる`・`Close` を自動操作してポップアップを閉じ、画面判定から再開（設定でOFF可能）
- 「初回起動スタート」と「2回目以降スタート」を選択でき、日付による自動判定は不使用
- 初回起動はアプリID起動 → URL 1を2回 → URL 2を2回（各10秒）→ TikTok Liteカードを終了 → 通常動作へ移行
- 2回目以降は1分スライド → カード終了・アプリID再起動を合計2回実行し、その後は10分ごとに同じ再起動を実行
- URL切替時は履歴画面の表示を待ってから「TikTok Lite」「TikTok-Lite」等を探索。横並び端末は左右、縦並びのRedmi・Xiaomi・POCO系は上下へカード一覧を移動し、通常端末は上方向、縦並び端末は横方向を優先して対象カードを終了
- 全範囲を探索してTikTok Liteカードがなければ既に終了済みと判定。対象カードを見つけても個別削除が全方向で失敗した場合だけ、履歴画面の全消去ボタン（横長ボタンまたは×）を最後の保険として使用
- URL表示中は `00秒経過 / 10秒待機` から毎秒カウントを更新
- URLの起動先選択が表示された場合はTikTok-Liteを最大3回まで自動選択
- 2つの起動URLはアプリ内で変更可能
- 面積約1/4の小表示と従来の大表示を切り替えられるフローティング操作パネル。操作ボタン以外の面からドラッグ移動でき、サイズと位置を保存
- 通常スワイプ速度は80〜1500msまで設定でき、「速い／標準／遅い」を併記
- 毎日2:00の予約開始（初期OFF、時刻と有効・無効を変更可能）
- バッテリー最適化の解除設定への導線
- 導入1〜5日目は120分、6日目以降は180分を標準実行時間に設定
- 実行時間終了時に画面をロック（Android 9以降）
- 実行中の通知、再接続時の残り時間復元、端末再起動後の予約復元
- THE FOOL QUESTと同じ表示方式のランチャーアイコン（通常＝背景透過、マスク用＝白背景）
- 起動画面は白背景にARUNO CLICKERのキャラクターを表示

### 端末間の起動URL同期

- 標準同期先は `https://aruno-clicker-config.45kikurage.workers.dev/v1/config` です。Cloudflare WorkerとD1を先にデプロイしてください。
- 各端末はアプリ起動時と自動スライド開始直前にURL 1・2を取得します。
- UI、フローティング操作、予約起動のどこから開始しても、動作開始前に最新URLを確認します。
- 通信に失敗した場合は最後に取得できた端末内URLのまま処理を続行します。
- 管理端末モードでは、好きな英数字8文字を初回のみサーバー登録できます。Android Keystoreで端末内に暗号化保存し、Bearer認証でURL 1・2を送信します。
- サーバーAPIは `GET` / `PUT` を同じ設定URLで受け付け、JSONは `{ "url1": "...", "url2": "..." }` を使用します。
- Worker/D1のソース、migration、テスト、デプロイ手順は `cloudflare-worker/` に含まれます。

## インストールと初期設定

1. APKをAndroid 8.0以降の端末へインストールします。
2. 初回画面の案内に従い、通知・他のアプリの上への表示・アクセシビリティを許可します。Android 13以降でアクセシビリティをONにできない場合は、アプリ情報の右上メニューから「制限付き設定を許可」します。
3. TikTok Liteが端末にインストールされ、ログイン済みであることを確認します。
4. ARUNO CLICKERの「開始」を押します。

その日のURL処理を行うときは「初回起動スタート」、URL処理を省略するときは「2回目以降スタート」を使用します。

Android 12以降で予約時刻の厳密な実行が必要な場合は、端末の「アラームとリマインダー」設定でARUNO CLICKERを許可してください。メーカー独自の省電力機能が強い端末では、電池の最適化対象外にする必要がある場合があります。

## 現時点の範囲

広告・写真・テキスト画像の判定はAccessibilityで取得できる可視中の文字・説明・ページ番号を利用します。サークルゲージはスクリーンショット内の外周リング、写真ページは中央下のドット列を端末内で判定します。リング内の猫などの画像は判定に使わないため、イベントで絵柄が変わっても外周リングを基準に動作します。Pマークの画像認識、管理用チェックイン、アプリ内更新はまだ含みません。

対象サービスの利用規約と地域のルールを確認し、自分の端末・アカウントで責任を持って利用してください。
